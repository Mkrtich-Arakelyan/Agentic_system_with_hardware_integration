### 1. Mathematical Formulation & State Equations

The underlying physical model is a driven Duffing-type oscillator:
$$\ddot{y} + a\dot{y} + b y + c y^3 = g u(t)$$

Let state $x = [y, v]^T \in \mathbb{R}^2$, where $y$ is displacement (output voltage $V_2$) and $v = \dot{y}$ is velocity. The continuous state-space equation parameterized by neural network $\alpha_\theta$ is:
$$\frac{d}{dt}\begin{bmatrix} y \\ v \end{bmatrix} = \begin{bmatrix} v \\ \alpha_\theta(y, v, u(t)) \end{bmatrix} = f_\theta(x, u(t))$$

#### Classical RK4 Discretization
With sampling frequency $f_s = 610.35\text{ Hz}$, the step size is $\Delta t = 1 / 610.35\text{ s} \approx 1.6384 \times 10^{-3}\text{ s}$.
For discrete time step $k \to k+1$ with input $u_k$ and $u_{k+1}$, we approximate intermediate input values linearly:
- $u(t_k) = u_k$
- $u(t_k + \frac{\Delta t}{2}) = \frac{u_k + u_{k+1}}{2}$
- $u(t_k + \Delta t) = u_{k+1}$

The standard RK4 integration step $x_{k+1} = x_k + \frac{\Delta t}{6}(k_1 + 2k_2 + 2k_3 + k_4)$ evaluates:
1. $k_1 = f_\theta(x_k, u_k)$
2. $k_2 = f_\theta\left(x_k + \frac{\Delta t}{2} k_1, \frac{u_k + u_{k+1}}{2}\right)$
3. $k_3 = f_\theta\left(x_k + \frac{\Delta t}{2} k_2, \frac{u_k + u_{k+1}}{2}\right)$
4. $k_4 = f_\theta(x_k + \Delta t \, k_3, u_{k+1})$

### 2. Initial Condition Estimation
For any sequence starting at time index $j$:
- Displacement: $y(t_j) = y_j$
- Velocity: computed via central difference when interior, or forward difference at boundary:
  - At the start of the full dataset ($j = 0$ of the excerpt): forward difference $v_0 = \frac{y_1 - y_0}{\Delta t}$ or second-order forward difference $v_0 = \frac{-3 y_0 + 4 y_1 - y_2}{2 \Delta t}$.
  - During sub-sequence training rollouts starting at index $j \ge 1$: central difference $v_j = \frac{y_{j+1} - y_{j-1}}{2 \Delta t}$.

---

### 3. Numerical Scaling
The measured signals $u$ and $y$ are small electronic voltages (typically on the order of $10^{-2}$ to $10^{-1}\text{ V}$), while finite-difference velocities $v \sim \frac{\Delta y}{\Delta t}$ can have substantially different magnitude, and accelerations $v' \sim \frac{\Delta v}{\Delta t}$ scale by $(1/\Delta t)^2$.
- Normalize inputs to $\alpha_\theta$: compute standard deviations $\sigma_y, \sigma_v, \sigma_u$ on the training split after zero-meaning.
- Feed normalized inputs $\tilde{y} = y / \sigma_y$, $\tilde{v} = v / \sigma_v$, $\tilde{u} = u / \sigma_u$ into $\alpha_\theta$.
- Scale the network output by an acceleration scale factor $\sigma_\alpha = \sigma_v / \Delta t$ or learnable multiplier so the neural network operates in an $\mathcal{O}(1)$ dynamic range.

### 4. Neural Network Architectures for $\alpha_\theta$

We propose two candidate architectures for comparison, balancing expressiveness, smooth nonlinear dynamics, and CPU training throughput:

1. **Architecture A (Baseline Smooth MLP - 2 hidden layers):**
   - Inputs: 3 ($y, v, u$)
   - Structure: `Linear(3, 64) -> Tanh() -> Linear(64, 64) -> Tanh() -> Linear(64, 1)`
   - Rationale: `Tanh` provides smooth $C^\infty$ dynamics with bounded gradients, natural for physical second-order oscillators.
2. **Architecture B (Deeper Swish/SiLU MLP with Linear Bypass):**
   - Inputs: 3 ($y, v, u$)
   - Structure: `Linear(3, 64) -> SiLU() -> Linear(64, 64) -> SiLU() -> Linear(64, 64) -> SiLU() -> Linear(64, 1)` plus a direct linear feedthrough `Linear(3, 1, bias=False)` to easily capture the dominant linear physical oscillator $-a v - b y + g u$.
   - Rationale: SiLU preserves smooth derivatives while the linear bypass allows fast convergence to the linear operating regime.
